# Ahammed Nawel — Cloud & DevOps Portfolio

A dark, cinematic, black-and-red Next.js portfolio inspired by the supplied reference video: oversized name typography, red ambient glow/particles, compact navigation, and scroll-reveal sections for About, Skills, Projects and Contact.

## Run locally

1. Install Node.js (LTS).
2. Extract this folder and open it in VS Code.
3. In the project folder, run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

## Important: personalize before sharing

Search the project for `YOUR_` and replace:
- `YOUR_EMAIL@example.com`
- `YOUR_GITHUB`
- `YOUR_LINKEDIN`

Also verify every skill and project description, add real repository links, and remove anything you have not actually worked with. The Video Portfolio section currently has three designed placeholders; replace them with your own YouTube/Vimeo embeds or approved video links and titles. The listed projects are presented as learning/personal projects, not professional employment.

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the repository.
4. Keep the default Next.js build settings and select **Deploy**.
5. Add your custom domain if you have one.

## Customize content

- Main content and project cards: `app/page.tsx`
- Colors, typography, responsive layout and animations: `app/globals.css`
- Browser title/description: `app/layout.tsx`

The contact links are placeholders until you replace them. The site does not currently send form submissions or collect visitor data.
